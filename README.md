# План: мобільний планувальник в одному файлі

## Призначення

Офлайн-апка для телефону (PWA): цілі → місяць → тиждень → день, звички, вхідні.
Увесь план — один текстовий файл формату [`.plan`](FORMAT.md). Його читає людина,
редагує ШІ і розпізнає апка.

## Файли

| Файл | Що це |
|---|---|
| `index.html` | Уся апка (без залежностей і збірки) |
| `sw.js` | Офлайн-кеш. Змінив `index.html` → підніми `CACHE` (`plan-v6`…) |
| `.nojekyll` | Каже GitHub Pages віддавати файли як є |
| `CLAUDE.md` | Що де лежить у коді і як працювати: для ШІ, якому передають роботу над апкою |
| `manifest.webmanifest`, `icon.svg` | Встановлення на головний екран |
| `FORMAT.md` | Специфікація формату `.plan` (давати ШІ) |

## Два репозиторії

| Репозиторій | Видимість | Що там |
|---|---|---|
| `plan-app` | публічний | ці файли; GitHub Pages роздає з нього апку |
| `plan-data` | **приватний** | один файл `plan.plan` і вся його історія |

На сайті лежить лише порожня апка без даних. План потрапляє тільки в приватний `plan-data`.

### 1. Апка (`plan-app`, публічний)

1. GitHub → **New repository** → назва `plan-app` → Public → Create.
2. Завантаж усі файли з цієї папки, разом із `.nojekyll`. Він потрібен, щоб Pages віддавав `FORMAT.md` як є.
3. **Settings → Pages → Build and deployment**: Source «Deploy from a branch», гілка `main`, папка `/ (root)` → Save.
4. За хвилину апка буде на `https://<логін>.github.io/plan-app/`. Відкрий цю адресу на телефоні в Chrome → меню → **Додати на головний екран**.

### 2. Дані (`plan-data`, приватний)

1. **New repository** → назва `plan-data` → **Private** → постав галочку **Add a README** (щоб зʼявилася гілка `main`) → Create.
2. Токен: аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
   - Repository access: **Only select repositories** → `plan-data`.
   - Permissions → Repository permissions → **Contents: Read and write**. Більше нічого не потрібно.
   - Expiration: на свій вибір. Коли термін закінчиться, апка напише «токен недійсний» — створиш новий.
3. В апці: **Файл → GitHub → Налаштування** → логін, `plan-data`, `main`, `plan.plan`, назва пристрою, токен → **Зберегти і синхронізувати**.
4. Повтори крок 3 на кожному пристрої. Новий пристрій із порожнім планом сам підтягне план з GitHub.

### Як працює синхронізація

- Зміни збираються й відправляються одним комітом: через 2 хв після останньої зміни, коли згортаєш апку, або кнопкою «Синхронізувати зараз».
- Під час відкриття апки, повернення в неї та появи мережі апка підтягує зміни з GitHub.
- Офлайн усе працює як звичайно. Помаранчева крапка на вкладці «Файл» означає, що є зміни, яких ще немає на GitHub.
- Якщо план змінили і тут, і на GitHub, апка спитає, що залишити. Нічого не губиться: або твоя версія ляже в `conflicts/`, або версія з GitHub лишиться в історії.
- **Історія** відкриває список комітів файлу. Будь-яку стару версію можна переглянути або відновити.
- Токен зберігається тільки на пристрої. Він дає доступ лише до `plan-data`.

### ШІ і репозиторій

На компʼютері Claude Code може працювати з планом напряму:

```bash
git clone https://github.com/<логін>/plan-data.git
```

Попроси його правити `plan.plan` за правилами з `FORMAT.md`, зробити коміт і `git push`. Апка на телефоні підтягне зміни, коли ти її відкриєш.

Перевірити локально на компʼютері:

```bash
python -m http.server 5173 --bind 127.0.0.1
```

і відкрити `http://localhost:5173`.

## Збереження

- План зберігається в памʼяті браузера на пристрої. Апка просить браузер не видаляти ці дані самостійно, але очищення даних сайту або скидання телефону їх зітре. Тому основна копія — приватний `plan-data`.
- **Файл → Експорт .plan** зберігає весь план одним файлом (на телефоні відкривається меню «Поділитися»).
- **Імпорт…** завантажує план з файлу, наприклад перенести з компʼютера на телефон.
- На компʼютері (Chrome/Edge) є **Звʼязати з файлом…**: кожна зміна пишеться у файл, а правки ззовні
  (Claude Code, будь-який редактор) апка підхоплює за кілька секунд.

## Робота з ШІ

1. **Файл → Копіювати для ШІ** копіює правила формату і весь план.
2. Встав у чат, допиши завдання («сплануй наступний тиждень, у мене пари пн–чт до 14:00»).
3. Скопіюй відповідь і натисни **Вставити відповідь ШІ**. Апка покаже, скільки рядків було і скільки стане, і попросить підтвердити.

## Швидке введення

У полі додавання: `! 10:00-12:00 Написати розділ`. Тут `!` позначає головну задачу, далі йде час (необовʼязковий), потім текст.
Для цілей поля розділяються ` | `: `Здати диплом | до 2027-06-01 | готово: захищено`.
Тап по квадратику ставить або знімає «зроблено». Кнопка `⋯` відкриває інші дії: редагувати, головна, перенести на завтра, підзадача, скасувати, видалити.
